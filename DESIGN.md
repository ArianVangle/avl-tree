# Дизайн. Лабораторная работа №1. Сбалансированное дерево поиска

## 1. Постановка задачи

### 1.1. Что реализуется

**Сбалансированное (AVL) бинарное дерево поиска** `BinaryTree<TKey, TValue>`, упорядоченное по ключу любого типа, у которого есть отношение «меньше». В узле рядом с ключом хранится значение. Над деревом реализуются: вставка, поиск, удаление, балансировка, `map`, `where`, `reduce`, извлечение поддерева и поиск его вхождения, сохранение в строку и чтение из строки по обходу, заданному строкой форматирования, перечислитель в любом из шести порядков, интерфейсы `ICollection` и `IEnumerable`, перегрузка операторов.

Одно и то же дерево — это **множество** (без значения) и **словарь** `IDictionary` (со значением). Значение может быть любого типа, в том числе без отношения порядка: функции, комплексные числа, записи студентов и преподавателей. Множество переводится в словарь и обратно.

Работа проверяется через консольный интерфейс и замеры времени на 10⁴–10⁸ элементах.

### 1.2. Общий класс задач

Хранение данных с быстрым поиском при сохранении их порядка: поиск, вставка и удаление за O(log N), перебор по возрастанию, k-й элемент по порядку, доступ к данным по ключу.

## 2. Сущности

### 2.1. Сущности

| Сущность | Описание |
|---|---|
| **Дерево** | Множество узлов с уникальными ключами. Для каждого узла ключи левого поддерева меньше, правого — больше его ключа. У каждого узла высоты левого и правого поддеревьев различаются не больше чем на 1. |
| **Узел** | Хранит ключ, значение (у множества — пустое), ссылки на левого и правого потомков, высоту и размер своего поддерева. |

### 2.2. Связи

```
 ┌────────┐ 1            0..N ┌────────────────┐
 │ Дерево │──── содержит ────▶│                │
 └────────┘                   │                │
                ┌─────────────┤      Узел      ├─────────────┐
                │ 0..1        │                │        0..1 │
                │ родитель    │ ключ, значение │    родитель │
                │             │ высота, размер │             │
                │ левый       │                │      правый │
                │ потомок     │                │     потомок │
                │ 0..1        │                │        0..1 │
                └────────────▶│                │◀────────────┘
                              └────────────────┘
```

| Связь | Кратность |
|---|---|
| Дерево — Узел («содержит») | дерево содержит **0..N** узлов (пустое — 0); каждый узел принадлежит ровно **1** дереву |
| Узел — Узел («левый потомок») | у узла **0..1** левый потомок; узел является левым потомком **0..1** родителя |
| Узел — Узел («правый потомок») | у узла **0..1** правый потомок; узел является правым потомком **0..1** родителя |

У корня нет родителя; у любого другого узла родитель ровно один — он либо левый, либо правый потомок.

Узел вместе со всеми потомками образует поддерево, которое само является деревом.

### 3.3. Решения

**Порядок задает тип ключа.** Дерево сравнивает ключи только отношением «меньше» самого типа, без внешнего параметра сравнения. Равными считаются ключи, ни один из которых не меньше другого. Ключи уникальны.

**Множество и словарь — одно дерево с параметрами `TKey`, `TValue`.** Значение лежит в узле рядом с ключом и в сравнении не участвует, поэтому может быть любого типа: функция, комплексное число, запись студента (ключ — номер зачетки).

- **Множество** `Set<T>` = `BinaryTree<T>`: параметр `TValue` по умолчанию — пустая структура `Empty`. Поле значения помечено `[[no_unique_address]]` и памяти не занимает.
- **Словарь** `Dictionary<TKey, TValue>` — наследник `BinaryTree<TKey, TValue>`, реализующий `IDictionary`: значение по ключу, замена значения, удаление с исключением. Поиск идет прямо по ключу, все операции — O(log N). Словарь — отдельный класс, потому что у множества `Get(index)` — k-й ключ, а у словаря `Get(key)` — значение по ключу.
- Все операции дерева — обходы, перечислитель, `map`/`where`/`reduce`, строки, поддеревья, операторы — работают по ключам и одинаково доступны множеству и словарю.

**Переход между множеством и словарем** — вставками ключей по возрастанию, O(N log N):

- `Keys()` — множество ключей словаря;
- конструктор `Dictionary(множество, f)` — словарь из множества, значение ключа — `f(ключ)`.

**Узел хранит высоту и размер поддерева.** Высота нужна для балансировки, размер — для получения числа элементов за O(1) и k-го элемента за O(log N). Оба пересчитываются по потомкам за O(1) после любого изменения потомков.

**Балансировка AVL.** После вставки и удаления узлы на пути к корню пересчитывают высоту; при разности высот поддеревьев ±2 выполняется поворот: малый — если высокий потомок перекошен в ту же сторону или ровный, большой (два малых) — если в противоположную. Высота дерева ≤ 1,44·log₂N, поэтому вставка, поиск и удаление — O(log N).

**Удаление узла с двумя потомками** — заменой на наименьший ключ правого поддерева вместе с его значением (у его узла нет левого потомка).

**k-й элемент.** Размер левого поддерева равен номеру узла среди элементов его поддерева; спуск по этому числу — O(log N).

**Владение узлами.** Каждым узлом владеет ровно один родитель (корнем — дерево). Копирование дерева — глубокое, передача дерева — перенос корня за O(1).

**`map`, `where` и слияние строят новое дерево вставками**, O(N log N): функция `map` может нарушить порядок или склеить разные ключи, поэтому форму исходного дерева копировать нельзя. `where` и слияние сохраняют значения.

**`reduce`** проходит элементы по возрастанию: `f(aₙ, … f(a₂, f(a₁, c)))`.

**Поиск вхождения поддерева.** Элементы уникальны, поэтому узел, соответствующий корню образца, находится обычным поиском за O(log N), затем сравниваются форма и элементы: O(log N + M).

**Строковое представление.** Каждая часть узла — корень (К), левое (Л), правое (П) — записывается в своих скобках в порядке строки форматирования, например `{К}(Л)[П]`; пустое поддерево — пустые скобки:

```
     2
    / \        {К}(Л)[П]  →  {2}({1}()[])[{3}()[]]
   1   3       (Л){К}[П]  →  ((){1}[]){2}[(){3}[]]
```

Скобки явно задают границы каждого поддерева, поэтому форма дерева восстанавливается однозначно при любом из шести порядков. Слева допустимы `( [ { <`, справа `) ] } >`, в том числе разные. Чтение — рекурсивный спуск по формату с последующей проверкой порядка и баланса.

**Перечислитель в любом порядке.** Порядок задается той же строкой форматирования, что и обходы. Перечислитель хранит стек пути от корня (у узлов нет ссылки на родителя): в стеке — узел и номер его следующей части формата. Шаг перебора берет верх стека:

- все три части пройдены — узел снимается;
- очередная часть К — узел выдается;
- Л или П — в стек кладется соответствующий потомок.

Один и тот же алгоритм дает все шесть порядков. Память O(log N), шаг в среднем O(1): каждый узел один раз кладется в стек и один раз снимается. Позиция хранится в перечислителе, а не в дереве, поэтому перечислителей у дерева может быть несколько. Перечислитель выдает ключ, а у словаря — и значение.

## 4. Функциональные требования

### 4.1. Дерево (`ICollection`)

- **Вставить** ключ (у словаря — со значением). Ключ уже есть — дерево не меняется, результат «не вставлено».
- **Найти** ключ.
- **Удалить** ключ. Ключа нет — дерево не меняется, результат «не удалено».
- **Число элементов**, высота, признак пустоты, очистка.
- **k-й ключ по возрастанию.** Индекс вне диапазона — исключение.
- После каждой вставки и удаления дерево сбалансировано.

### 4.2. Функции высшего порядка

- **`map(f)`** — новое дерево из `f(элемент)`; совпавшие результаты хранятся один раз.
- **`where(p)`** — новое дерево из ключей, для которых `p` истинно, вместе с их значениями.
- **`reduce(f, c)`** — свертка по возрастанию; для пустого дерева — `c`.
- **Слияние** (`+`) — объединение элементов двух деревьев без повторов.

### 4.3. Поддеревья

- **Извлечь поддерево** с корнем в заданном элементе — независимая копия. Элемента нет — исключение.
- **Проверить вхождение поддерева** — совпадение формы и элементов. Пустое поддерево входит в любое дерево.

### 4.4. Строковое представление

- **Строка форматирования**: буквы К, Л, П по одному разу, каждая в скобках. Иначе — исключение с описанием.
- **Сохранить в строку** по фиксированному обходу (`{К}(Л)[П]`) и по строке форматирования. Элемент невозможно записать (пустой, пробелы по краям, содержит закрывающую скобку корня) — исключение.
- **Прочитать из строки** по фиксированному обходу и по строке форматирования; восстанавливается та же форма. Синтаксическая ошибка, неверный элемент, нарушение порядка или баланса — исключение. Пустая строка — пустое дерево.
- Для записи и чтения тип элемента должен поддерживать потоковый вывод и ввод.

### 4.5. Перебор (`IEnumerable`)

- Получить перечислитель: по возрастанию (`IEnumerable`) или в порядке, заданном строкой форматирования, — любой из шести. Неверная строка — исключение.
- Следующий, текущий ключ, значение текущего узла, сброс.
- Текущий элемент до первого шага или после конца — исключение.
- Изменение дерева делает перечислитель недействительным.

### 4.6. Операторы

- `==`, `!=` — совпадение множеств элементов;
- `+` — слияние;
- `<<` — вывод строкового представления по фиксированному обходу.

### 4.7. Словарь (`IDictionary`)

- **Добавить** пару (ключ, значение). Ключ уже есть — значение заменяется.
- **Получить значение по ключу.** Ключа нет — исключение.
- **Проверить наличие ключа.**
- **Удалить по ключу.** Ключа нет — исключение.
- **Число пар.**
- Все операции дерева (обходы, перечислитель, строки, поддеревья, `map`/`where`/`reduce`) — по ключам.

### 4.8. Переход между множеством и словарем

- **Множество ключей словаря.**
- **Словарь из множества** — значение каждого ключа вычисляется функцией от ключа.

### 4.9. Типы

- Ключ: тип с отношением «меньше» — целые, вещественные числа, строки.
- Значение словаря: любой копируемый тип — комплексные числа, функции, студенты, преподаватели.

### 4.10. UI

- Вставить, найти, удалить элемент; получить k-й элемент; очистить.
- Заполнить автоматически: количество, диапазон значений, seed.
- Показать дерево и шесть обходов; перебрать перечислителем в порядке, введенном строкой форматирования.
- Выполнить `map`, `where`, `reduce`, слияние.
- Извлечь поддерево, проверить вхождение поддерева.
- Сохранить в строку и прочитать из строки с вводом строки форматирования.
- Показать работу с остальными типами через дерево и словарь, переход множество → словарь → множество.
- Ошибка ввода или операции — сообщение, программа продолжает работу.

### 4.11. Замеры

- Время вставки, поиска и удаления N случайных элементов, N от 10⁴ до 10⁸.
- Результаты сохраняются в файл и выводятся графиком зависимости времени от N.
